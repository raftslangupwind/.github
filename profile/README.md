## ❓ Frequently Asked Questions (FAQs)

#### 1. What is the difference between "Uninstall" and "Uninstall quietly" in BCUninstaller?

"Uninstall" launches standard interactive application setup windows requiring manual click-throughs. "Uninstall quietly" attempts to pass silent parameters (like `/S` or `/quiet`) to run uninstallations automatically in the background without pop-ups.

#### 2. Is Bulk Crap Uninstaller safe for commercial and business environments?

Yes. BCUninstaller is licensed under the Apache 2.0 open-source license, allowing it to be used freely in personal, corporate, and IT servicing environments.

#### 3. Does BCUninstaller create a safety backup before removing software?

Yes. BCUninstaller prompts you to create a standard Windows System Restore Point before initiating batch uninstallation, and provides options to backup registry leftovers prior to deletion.
